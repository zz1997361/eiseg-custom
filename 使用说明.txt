EISeg 交互式分割标注 —— 使用说明
================================================

一、启动
  双击「启动EISeg.bat」，几秒后出现 EISeg 窗口，模型已自动加载好，无需手动选模型。

二、打开要标注的图片
  菜单「文件 → 打开文件夹」，选择存放图片的文件夹。
  打开后，标注结果会保存在该文件夹下的 label 子目录里。

三、基本标注（点几下就出轮廓）
  1. 先在左侧标签列表点选要标的类别（例如 ground 或 person）。
  2. 在目标上【左键】点几下：左键 = 正点（“这里属于该目标”）。
  3. 若区域多圈进来了不想要的部分，在那些地方点【右键】：右键 = 负点（“这里不要”）。
     反复左键/右键点击，模型会实时刷新分割范围，越点越准。
  4. 满意后按【空格键】完成当前目标（变成可编辑的多边形），然后可继续标同一张图里的下一个目标。

四、翻页
  A = 上一张        D = 下一张

五、保存
  - 手动保存：菜单「保存」（对当前这张保存）。
  - 推荐：按【X】开启「自动保存」，之后每次用 A/D 翻页时会自动保存上一张，
    这样一路标下去不用手动点保存。
  - 保存格式在菜单里可勾选：灰度、伪彩色、COCO 等（默认已勾 COCO + 灰度 + 伪彩色）。

六、微调与修正（重点）
  1. 完成前（还在点阶段）：
     - Ctrl+Z 撤销上一次点击，Ctrl+Y 重做。
     - 点错了就继续用右键/左键补点修正，不必重来。
  2. 完成后（已是多边形）想再改：
     - 单击选中该多边形，出现顶点（小方块/把手）。
     - 拖动某个顶点 = 调整轮廓位置。
     - 双击某个顶点 = 删除该顶点（简化轮廓）。
     - 需要更多控制点时，可在轮廓上继续加点后再调整。
     - 整个目标标错/想重画：选中它后按【Backspace】删除该多边形，重新点。
  3. 勾掉零碎的误检小块：菜单勾选「保留最大连通块」，只留最大的那块。
  4. 清除当前这张的所有标注：菜单「清除所有标注」(Ctrl+Shift+Z)。

七、快捷键一览
  A            上一张
  D            下一张
  空格          完成当前目标
  左键          添加正点（包含）
  右键          添加负点（排除）
  双击顶点      删除该顶点
  Backspace    删除选中的多边形
  Ctrl+Z       撤销上一次点击
  Ctrl+Y       重做
  X            自动保存开关（翻页即保存）
  Ctrl+Shift+Z 清除所有标注
  E            打开“编辑快捷键”窗口（可自行改键）
  （快捷键可在「编辑快捷键」里自定义。）

八、环境要求
  64 位 Windows 10 / 11；纯 CPU 运行，不需要显卡；解压后约占 1.5 GB 磁盘空间。

九、常见问题
  Q：双击 bat 后窗口一闪而过 / 打不开？
  A：多为解压路径含中文或空格，或杀毒软件拦截。请把文件夹放到纯英文无空格路径，
     并允许本文件夹内 pythonw.exe 运行；可看同目录下 eiseg_error.log 的报错。

  Q：模型没自动加载？
  A：确认 models\static_hrnet18_ocr64_cocolvis\ 下的 .pdiparams 与 .pdmodel 两个文件完整。

（本版本为手动/半自动交互式标注，不含批量自动预标注。）
